ButtonsText, icon, toggle.

There are three button types, and all three are real <button> elements. There is no highlighted "primary" button: in the blueprint language an action stands out by its position and label, not by its color.

Classes
.btn · .icon-btn · .toggle-btn · .is-accent · .pillrow
State
aria-pressed (toggle) · disabled · aria-disabled="true"
JS
Not required; a one-line page script for toggles

01

Variants

Text button, icon + text, and icon only. All are 32–34px tall; side by side, their baselines line up.

Example · three types

An icon button with no visible text requires aria-label. The icon comes from the sprite via <svg><use href="#i-…"/></svg>; the button sets its size (14px / 16px).

02

Toggle

A button that turns a setting on and off carries its state in aria-pressed. The default color is red: the pressed state blocks or bypasses something. Use .is-accent for a harmless option.

03

States

A disabled button is drawn with a dashed border and faded ink: in this language a dashed line means “not real yet”. There are two ways to do it; the difference shows up on the keyboard.

05

Do / don't

A button is an action; a link is a place. The label starts with a verb and says what will happen.

Do · verb + object
Don't · vague label, unnamed icon
Accessibility

Keyboard focus on every button is a 2px accent ring (:focus-visible). Try it with Tab. An element that changes the page should be an <a>; the .btn class works on links too.
