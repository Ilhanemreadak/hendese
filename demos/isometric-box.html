Isometric boxDraw a closed unit with three faces.

An isometric box shows a server, a storage tier or a message in a queue with shadowless depth: the front face is paper, the top and side faces one shade darker than the background (.fill-shade). The recipe uses only the package's line and fill classes; no new class is needed.

Classes
.ln-draw · .ln-strong · .ln-dash · .ln-ghost · .fill-paper · .fill-shade
Face shade
--scene-shade = --scene-bg + 8% drawing color
Offset
large dx +36, dy −22 · small dx +20, dy −12
JS
Not required

01

Anatomy

The front face is a W × H rectangle. The top and right faces are parallelograms of the same edges, offset by dx, dy. The light always comes from the same direction.

Example · faces and dimensions

Front face.fill-paper · W × H

Top face.fill-shade · --scene-shade

Offsetdx = +36 · dy = −22

Side face.fill-shade

Drawing order matters: the top and side faces first, the front face last. That way the front face's paper fill covers the edge joins cleanly. The corner ticks (.ln-pencil) are optional; on large boxes they mark the face's frame.

The top and side faces are painted with .fill-shade: the --scene-shade token is one shade darker than the scene background. So the box reads with all three faces both on a plain page and on a sheet whose background is already --scene-bg (.fig-sheet, .frame).

02

Stacks

When boxes are stacked, the top face of the lower box ends up under the upper one. Draw from the bottom up; each new box covers the lines of the one below.

To seat an upper tier on the top face of the one below, move its front face back and up by half the offset (here +14, −8.5, then inset from the edges). A box flush with the edges reads as a single block instead of tiers.

The top and side faces can be written in a single <path> (two subpaths, each closed with Z); then the state class goes on just two elements. A ghost box has no fill: whatever is behind it shows through, because that part isn't there yet, or is no longer there.

06

Do / don't

Every box uses the same offset; the front face is always paper. If the light comes from two directions, the drawing plane breaks.

Do · one offset, paper front face

api

worker

dx +20, dy −12 · the same on both boxes

Don't · inverted faces, mixed directions

api

worker

front face is shaded, the second box faces left

Do · .fill-shade on a sheet
Don't · .fill-scene on a sheet
No shadows

Only the faces give depth; don't add filter: drop-shadow, a gradient or a semi-transparent dark fill. The box's meaning lives in its label and .state word, and the SVG stays aria-hidden="true".
