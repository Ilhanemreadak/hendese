Intro

Hendese · Blueprint

Station explorerEvery stop in the drawing is a clickable button.

The explorer turns the stops of a drawing into real <button> elements. Hovering or focusing previews, clicking selects; the selected stop's description appears in the panel under the sheet. A page can have as many explorers as you like.

Classes
.station · .svc-* · .st-name · .st-sub · .st-meta · .st-detail · .sl · .deck-cap
Attributes
data-explorer · data-key · aria-pressed · data-for
Event
hendese:explore → detail.key

01

Anatomy

Three parts: a container that carries data-explorer, buttons inside it that carry data-key and aria-pressed, and a panel whose id equals the data-explorer value.

Example · the smallest explorer · CDN path

miss

Client. Sends the request to the nearest edge; the address comes from DNS.
Edge. If the response is cached and fresh, it returns without going to the origin at all. Hit rate 94%.
Origin. Called only on a miss; sends the response back together with a Cache-Control header.
  • Container: data-explorer="ig-cdn". The value is the panel's id, so it must be unique on the page.
  • Buttons: [data-key][aria-pressed]. A button without both doesn't join the explorer. The one that starts with aria-pressed="true" is selected; otherwise, the first button.
  • Panel: [data-for="key"] blocks. If JavaScript doesn't run, and in print, all blocks show one under another (the finished state); JS writes the .show class.
  • aria-controls links the button to the panel, and aria-live="polite" links the panel to the screen reader.

02

States

A stop carries one, two or three lines. Hover gives a thin inner line, selection a heavy inner line and the SELECTED badge, keyboard focus an accent ring.

Example · line count, selection and color

name only

name + subline

selected · three lines

--svc: var(--bad)

.st-name on its own. Without --svc, the square mark takes the drawing color.
.st-sub is the second line, in plain text. The square is purple via --svc: var(--sec).
.st-meta is the third line, mono and faded. This stop starts selected: aria-pressed="true".
Color stays in the square only; the frame is the same on every stop. The ready-made .svc-* classes set the same variable.

Lines are cut with text-overflow: ellipsis; a long name doesn't grow the stop. Font sizes scale with --u and never go below 10.5px. The badge text comes from the --str-selected token; override it for another language.

Example · service marks · .svc-*
.svc-gitlab colors the square in the source repository's color. The class only sets the --svc variable; the frame and text don't change.
.svc-aws for cloud services: build, registry, queue.
.svc-argo for the syncer that carries the desired state in the repository to the cluster.
.svc-k8s for workloads running in the cluster. The color tells the service; a word still tells the status.

For service color, use the ready-made class instead of writing an inline --svc: .svc-gitlab, .svc-aws, .svc-argo, .svc-k8s. The color stays in the small square; the service name is always written in the subline too.

03

In context

The explorer usually lives inside a sheet: the drawing in the f-map area, the panel in the f-foot area, right under the one-sentence summary.

The five stops of a backup

Click a stop or focus it with Tab; the panel below describes that stop.

The top row captures and protects the data; the bottom row keeps it until it expires and tests it regularly. The ghost box is a stage that isn't built yet, and it can't be clicked.

INTAKECapture and protect

RETENTIONKeep and test

archive · planned

In one sentenceThe nightly snapshot is encrypted, copied to a second region, kept for 35 days and tested every month with a real restore.

Snapshot. A disk-level consistent copy of the database. It doesn't stop writes; there may be an I/O pause of a few seconds.
Encryption. The snapshot is encrypted with the key in the vault. When the key rotates, old snapshots keep being read with the old version.
Copy. The encrypted snapshot is sent to the second region; if a region is lost, the restore runs from here.
Retention. Snapshots are kept for 35 days. While the delete lock is on, an unexpired snapshot can't be deleted even by hand.
Test. Every month a random snapshot is restored to a temporary copy and check queries are run. An untested backup doesn't count as a backup.

Fig. 1. Five stops, clockwise. The dashed line is the border between intake and retention; the ghost box is a planned but unbuilt archive.

04

Event: hendese:explore

When a selection is made by click, the container dispatches a bubbling hendese:explore event. Previews don't dispatch it; neither does the initial selection.

Example · the last selection of the two explorers

No selection yet. Click a stop in one of the two explorers above.

e.target is the container itself; detail.key is the data-key value of the selected button. Use the event to write to the address bar, send a metric or update another drawing. To change the selection from code, call click() on the matching button.

05

Do / don't

A stop is a button; a stop with no panel, or one the keyboard can't select, isn't an explorer, just a picture.

Do · button + linked panel
Primary. All writes come here.
Replica. Serves reads; lag 0.4 s.

Primaryorders-db-1
Replicaorders-db-2
Accessibility

Stops are visited in Tab order; focus opens the preview, Enter or Space selects. A screen reader reads the button as “pressed / not pressed” and, thanks to aria-live, announces the new text when the panel changes. On narrow screens (below 720px) the SVG is hidden and the stops stack; that is why the sentence that explains the arrows must also be in the panel or the summary.
