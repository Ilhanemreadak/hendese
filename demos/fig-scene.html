01

Anatomy

One sheet, one choice, one drawing, one result line. Hoca is optional and speaks only in live mode.

.fig-sheet is a figure that stays in the flow; it doesn't stick and has no track. The choice controls (.choice, buttons) are wired to the page's own script and work with motion off too. figScene, on the other hand, calls render(api, t, vis) on every frame while the scene is visible: t is the time in milliseconds, vis is the visible share of the figure (0..1). Hoca can be requested while at least 45% of the figure is visible.

Division of labor

The page holds the state and updates the drawing and the result line. The scene returns Hoca's pose and speech bubble, and says busy: true while a timed beat is running. When the state changes, the page wakes the loop with fig.poke().

02

Live example · connection pool

Thirty concurrent requests arrive at a database connection pool of the chosen size. If the pool isn't big enough, requests wait in a queue.

03

Timed beat · certificate renewal

Press the button and Hoca stamps for a second and a half, then returns to a calm pose. As long as it returns busy: true, the loop doesn't sleep.

Sleep

When the beat ends, render returns busy: false and the engine sleeps on the next frame; Hendese.state.idle becomes true again. Returning busy: true all the time never lets the loop sleep.

04

With motion off

The controls work in every mode; only Hoca changes. The result line carries the meaning.

With reduced motion, below 1100px and in print, the two figures above work the same: the radio buttons update the squares and the line, and the result line (aria-live="polite") states the new state in text. Transitions are defined only under html.motion, so the change is instant.

On desktop with reduced motion on, Hoca sits in the drawing as a still copy in the pose the still function returns. When still is a function, its value is reread on every Hendese.refresh() call; that is why every handler that changes the state calls refresh() at the end. Timed beats (stamp, speech bubble) don't play at all with reduced motion.

Without JS the controls have no purpose; on this page the html:not(.js) .fs-sheet .choice rule hides them, and the figure shows the default state from the markup (40 connections, 90 days).

05

Do / don't

The figure is played to learn; the result is always written in text too.

Do · the result line states the state

Queue forming. 10 of 30 requests are waiting for a connection; grow the pool or shorten the queries.

Don't · meaning only in color

See the red circles.

Do · a short beat, then sleep

The beat lasts 1–1.5 seconds; busy is true only during that time. Hoca speaks once and repeats what the result line says.

Don't · constant animation

If render always returns busy: true, the loop never sleeps and battery and CPU are wasted; you have also bypassed reduced motion.
