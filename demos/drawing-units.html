Drawing unitsDraw in your own coordinates, read at any width.

.drawing defines a drawing in its own unit system: the SVG viewBox and the HTML labels share the same coordinates and scale together with the drawing's container. Dimension lines, callouts, state labels and stations sit on top of this system.

Classes
.drawing · .dl · .dim · .dim-t · .callout · .state · .oneliner · .station
Variables
--aw · --ah · --u · --x · --y · --w · --h
JS
Not needed (the explorer, for stations)

01

Anatomy

The drawing area is aw × ah units. The SVG is drawn with the same viewBox and the HTML labels are positioned in the same units; the two stay aligned at every width.

Example · a load balancer on an 800 × 300 unit grid

Load balancerlb-public · :443

web-1 · 10.0.1.11

web-2 · 10.0.1.12

web-3 · 10.0.1.13

  • --aw and --ah on .drawing set the aspect ratio and the number of units; the inner <svg viewBox="0 0 aw ah"> uses the same system.
  • A .dl label is positioned in the same units with --x, --y and --w. No height is given; the text flows down.
  • --u is the pixel size of one unit (100cqw / aw). Write font sizes like max(10.5px, calc(12.5 * var(--u))): they grow but never become unreadable.
  • With vector-effect: non-scaling-stroke lines keep the same weight at every scale; <text> inside the SVG grows with the drawing.

02

Dimension lines

A dimension line states a length or a duration: two extension lines, a dimension line with arrows, and the value. All of it is one .dim path; the value is a .dim-t text.

Example · the life of a message in a queue

Queuejobs-eu

enqueued

received

deleted

returns if the timeout expires

A dimension path has three parts, written in this order:

  1. extension lines: M240 132V92;
  2. dimension line: M240 100H480;
  3. arrowheads: l8-3v6z.

In chained dimensions the middle extension line belongs to both dimensions; arrowheads meet it from both sides. A vertical dimension's value is rotated with rotate(-90).

03

Label, callout and state

A name inside a box is written with .dl, a note outside a box with .callout, a status with .state. A one-sentence summary of the drawing sits below with .oneliner.

In one sentenceObjects stay hot for 30 days and cold for a year, then are deleted permanently.

The callout box is HTML; its leader line is drawn in the SVG and ends at the box's left edge, level with the first line, so the line does not break when the text grows. The leader connects to the object with a dot (circle.fill-draw).

.state also gives its color to the frame through currentColor; color alone carries no meaning, and the label is always a word. Used outside a drawing, where there is no --u, it assumes 1px.

04

Station positioning

Clickable stations are placed in drawing units too: --x, --y, --w and --h. When the scale changes, the buttons grow with the drawing; their corners are square like the boxes in the drawing.

Example · producer, queue, workers

publish

pull

--x: 20 · --y: 50

Producer. Drops one message into the queue for each order event and returns without waiting.
Queue. Holds messages in order; a received message is hidden from other workers for the visibility timeout.
Workers. Four replicas pull from the same queue. This station sits 10 units higher and is 10 units taller: --y: 40; --h: 100.

.station and .sl inherit --aw / --ah from the nearest .drawing; if none is set, 1000 × 600 is assumed. A station has square corners (border-radius: 0): like every drawn object it is not rounded, so it shares a line with the SVG boxes. For explorer behavior, see the Station explorer page.

06

Do / don't

A label is HTML: selectable, translatable, and it wraps if it does not fit the box. SVG text is only for short dimension values.

Do · label with .dl

Backup vaultsnapshots taken nightly at 02:00 are kept for 35 days

Don't · long text inside the SVG
Accessibility

The SVG always carries aria-hidden="true"; the dimension values inside it never reach a screen reader. If a number carries meaning, repeat it in a .dl, a .oneliner or the caption. In the example on the right, the text never reaches a screen reader and overflows the box.
