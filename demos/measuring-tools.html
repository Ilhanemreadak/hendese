Hendese · Blueprint

Measuring toolsMeasure a value against a rule, show the gap.

There are two tools. The caliper measures a string against a regular expression character by character: where it passes, where it fails, what is missing. The dial and the linear gauge show the desired value and the actual value on the same scale; the gap between them is marked and also stated in words.

01

Caliper

The fixed jaw ^ sits at the start of the string, the sliding jaw $ at the right edge of the last cell. Each character is a cell; the line under it is the pattern part that measures that cell.

Example · a version tag that does not match the pattern

v2.13.0-rc1

^v

\d+\.\d+\.\d+

$

No match Character 8, -, is not expected: the pattern must end with the version number, and a pre-release suffix is not accepted.

apassed xfailed missing bnot checked

The measured string is v2.13.0-rc1, the pattern ^v\d+\.\d+\.\d+$. The cells are the package class .cells: each character is an <i>, 26 units wide, and its text scales with the drawing through --u. The jaws and the ruler are in the SVG; the pattern parts and the verdict are in HTML labels. The four cell states:

  • passed · .s-ok: a thin border, a green underline;
  • failed · .s-bad: a heavy red border, a light red fill; data-mark puts a ▲ below;
  • missing · data-state="miss": the same, but dashed and empty: the pattern expects a character, and the string has ended;
  • not checked · data-state="ghost": dashed and faint: the measurement stopped earlier.

02

Caliper results

The same tool with two verdicts: when everything passes, only green lines remain; when the string is too short, the sliding jaw stops beyond an empty cell.

Example · branch name · match

release/2026-10

^release/

\d{4}

-

\d{2}$

Match All 15 characters match the pattern; the branch counts as a protected release branch.
Example · secret key name · missing

db-pass-v

^db-pass-v

\d+$

No match The version number is missing: the pattern expects at least one digit at the end, and the string ends with v.

03

Dial

The thin needle with an arrowhead shows the desired state, the heavy needle the actual state. The gap between them is marked with an orange arc; the number and the word are written above the dial.

Example · 6 replicas desired, 3 running

Gap · 3 replicas

desired · 6

actual · 3

web-api · scale: replica count

The scale is 0–14 replicas, 10° per replica; the value 0 sits at −70°. The needles are drawn vertical and the angle is set with a single rotate. The desired value is drawn with .needle (thin, with a .tip arrowhead), the actual value with .needle.is-actual (heavy ink). The .needle class ties rotation to view-box coordinates; the dial center is given with --ox / --oy (on the needle or on a shared parent). When the value changes, only the angle changes; the gap arc is drawn between the same angles at a slightly larger radius.

04

Linear gauge

The dial laid flat: for when the value range is horizontal or space is tight. The acceptance zone is shaded in a light color, the threshold drawn with a thin arrow, the actual value with a heavy bar.

Example · replica lag

desired · at most 2 s

actual · 6.2 s

Lagging

The orders-db-3 replica is 6.2 seconds behind the primary; the acceptance zone is 0–2 seconds. The orange line is the gap itself (4.2 s). The scale is linear: 80 units = 1 second. The acceptance zone is painted with class="fill-soft s-ok"; the needles are the same .needle (desired) and .needle.is-actual (actual) classes as on the dial.

06

Do / don't

A gauge shows a number but does not replace it. The desired and actual values must be written out, with their units.

Do · value, unit and verdict

p95 threshold · 200 ms

actual · 380 ms

Slow gap 180 ms

Don't · marks alone
Accessibility

The caliper's cells are HTML, but a screen reader reads them letter by letter; the dial's numbers are inside the SVG and never reach it. The verdict (.state + a sentence) must always be written in HTML: which character, which value, how big the gap. Color alone is not enough; failed and missing cells are also told apart by border weight and pattern.
