Hendese · Components

BadgesState and ownership in one word.

Three small labels: the round, colored .pill, the square, uppercase .state, and the backgroundless mono .chip. None of them is clickable; they sit next to a row, a heading or a figure and say what it is or what state it is in.

Classes
.pill · .state · .chip
Status
.s-ok · .s-warn · .s-bad · .s-sec · .s-neutral · .s-accent · .s-gitlab · .s-aws · .s-k8s · .s-argo
Variables
--c (line + text), --c-soft (background), --u (.state scale, default 1px)
JS
Not needed

01

Anatomy

The three labels do different jobs. A pill carries the type or result of something, a state the current status in a drawing or a record, and a chip the name of a figure or section.

02

States

Color comes from the .s-* classes and sets two variables together: --c paints the line and text, --c-soft the background. The same class means the same thing on .pill and .state.

Example · status colors, pill and state
passed slow down secret on hold new no class

done retrying timed out awaiting signature queued selected

Example · service colors, background included
source repo eu-west-1 cluster sync

Service classes now set the background themselves: 10% of the --c color. Older style="--c-soft:color-mix(…)" lines can be deleted. A .pill with no class is neutral, and so is .state. Color reinforces meaning, it does not carry it: each badge's word states the status on its own.

Example · --c does not leak into a nested component
Disk almost full

logs-db is 91% full · owner platform · last backup succeeded

The warning box sets --c to yellow; the unclassed badge inside it still stays neutral, because every component defines its own defaults for --c and --c-soft. Badges used to inherit the container's color.

03

State label

state comes from the drawing language: square, uppercase, no background; its line and text in the --c color. Without a class it is neutral.

Example · four states

queued done retrying timed out

Its size is computed from the drawing unit --u: max(9.5px, 11 × --u). Inside a drawing, --u comes from the drawing's width; outside a drawing it defaults to 1px, so you need not set it. For a larger label, enlarge the unit; the smallest size stops at 9.5px.

05

Do / don't

A badge is a word; not a sentence, and never a button. Color reinforces meaning but does not carry it alone.

Do · the word states the meaning
passed failed
Don't · meaning only in color
test test
Do · one word, details alongside

on hold The owner is on leave; it will be taken over on October 14.

Don't · squeezing a sentence into a badge

owner on leave, takeover on october 14

Accessibility

Badges are plain text; screen readers read the word, not the color. So the status word must make sense on its own. Do not add click behavior to a badge; if you need a filter or a selection, use .toggle-btn or .choice. If the status changes live, give the container aria-live="polite".
