Intro

Hendese · Motion

Sketch and revealTwo small motions, no scene needed.

The pencil sketch draws a drawing in pencil in two seconds; [data-reveal] fades an element in as it enters the viewport. Neither needs a scene registration, and both show the finished state directly in unsupported browsers and under reduced motion.

Classes
.sketch-pending · .sketch · .pencil (SVG group)
Attribute
data-reveal · data-reveal="draw"
JS
Sketch: a few lines that swap two classes. Reveal: none (animation-timeline: view())

01

Anatomy

Two tools, two separate jobs. The sketch shows how a drawing is built; the reveal adds a small accent to the reading flow.

Pencil sketch. First .sketch-pending is added to the container (the pencil paths become invisible), then on the next frame it is swapped for .sketch: every path in the .pencil group is drawn in two seconds (--dur-5) with a stroke-dashoffset transition. The paths must carry pathLength="1"; short and long paths finish at the same time.

[data-reveal]. The element fades in as it enters the viewport; data-reveal="draw" draws the SVG shapes inside it instead. The timing is pure CSS (animation-timeline: view()) with no JS, and scrolling back rewinds the animation.

02

Live example · pencil sketch

A network plan is drawn in pencil first, then the ink lines and labels arrive. The figure plays once when it enters the viewport; the button replays it.

Ink delay

The package only draws the pencil paths. Having the ink and labels arrive after the sketch is this page's own rule: .sketch-pending .ts-ink{opacity:0} and .sketch .ts-ink{transition: opacity … 1.8s}, both inside @media screen.

Variation · pencil only

A rack plan drawn in pencil with a dimension line and no ink layer. The same two classes, different content; the labels still arrive after the sketch.

The sketch also plays below 1100px; that limit applies only to the scene engine. If you do not want it to play on narrow screens, check Hendese.state.motion before adding sketch-pending.

05

Do / don't

Reveal is a decoration layer; it must not slow down reading or hide information.

Do · a small accent
Tip

A note, a figure, a line: a few places on the page.

data-reveal on self-contained elements like tips and figures.

Don't · every paragraph fades in

When every paragraph and list item carries data-reveal, the text stays a step behind the reader; a fast scroller sees half-transparent lines.

Do · visible by default

Hiding happens only in the package, under @supports and prefers-reduced-motion: no-preference. Page CSS does not hide the element.

Don't · your own opacity:0

A page rule like [data-reveal]{opacity:0} hides the content for good in an unsupported browser.

06

API

The package provides two classes and one attribute; timing and triggering belong to the page.

MemberWhat it does
.sketch-pendingOn the container: paths inside .pencil are invisible (stroke-dashoffset: 1). Screen only.
.sketchOn the container: paths are drawn over --dur-5 (2 s). .sketch-pending must be set one frame earlier.
.pencilSVG group; pencil color and weight. Its paths require pathLength="1".
data-revealOpacity and a 12px shift as it enters the viewport (entry 0% → entry 60%).
data-reveal="draw"Draws the path, line, polyline, rect, circle shapes inside it (entry 10% → cover 45%); the shapes require pathLength="1".
ConditionReveal: @supports (animation-timeline: view()) and prefers-reduced-motion: no-preference. Sketch: @media screen.
