Hendese · Components

Checkbox, radio and rangeNative controls, drawing color.

Checkboxes, radio buttons and range sliders are the browser's own elements; the package only sets their color (accent-color) and their alignment with the label. Groups are named with <fieldset class="field"> and <legend>; a slider's value is written in the <output> element next to it, in tabular figures.

Accessibility

On entering a radio, a screen reader first reads the legend text; a heading given as a paragraph does not create that link. In a radio group Tab is a single stop, and the arrow keys change the selection. On a slider, arrow keys move one step, Page Up/Page Down a large step, and Home/End go to the ends. <output> may act like a live region in a screen reader; since the slider already reads the value, do not add a second aria-live outside the result line.
