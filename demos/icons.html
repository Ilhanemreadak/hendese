IconsThirteen line icons, one sprite.

Icons are called with <use href="#i-…"> from an SVG sprite pasted once at the top of the page. All of them are drawn on a 24-unit grid with 2-unit, round-capped lines, and take their color from currentColor.

In large text, the icon grows too.

Every <svg> in the source that has no viewBox and directly contains a <use> takes its size from the text: 1em × 1em. To change the size, touch the container's font-size, not the icon. The rule sits inside :where(), so its specificity is zero; component sizes (such as .btn svg at 14px) and your own classes always win.

base.css makes every svg a block. For an icon inside a sentence, add .ic: it becomes inline-block, sits on the baseline and doesn't shrink inside flex. The style="width:16px;height:16px" workaround from 0.1 is no longer needed.

02

Sizes

The line weight is 2 units on a 24-unit grid; at 12px it drops to one pixel. Don't go below 12px, and above 24px use a drawing instead of an icon.

Inside components

04

In context

An icon either shortens an action or marks a status. In the second case the icon carries meaning and must be announced to screen readers by name.

05

Adding a new icon

A new icon goes into src/icons.svg as a symbol. Same grid, same weight, same cap style; otherwise it sticks out next to the other thirteen icons in the sprite.

Preview · before adding
Try the new drawing next to the existing icons, at the same size.

  1. Add the symbol

    The id starts with i-; viewBox 24×24, no fill, stroke currentColor. Don't hard-code a color: the icon would ignore the theme and the component.

  2. Build

    npm run build copies the sprite to dist/icons.svg. Part pages (node tools/demos.mjs) read the sprite straight from src/icons.svg.

  3. Carry it to the pages

    The sprite is inline on every page. A new page starts as a copy of docs/_template.html (the sprite is inside); when src/icons.svg changes, the sprite on existing pages is updated by hand.

Contract

Icon ids are part of the documented contract. Adding an icon is a minor release; renaming or removing one needs a major release.

06

Accessibility

The sprite itself carries aria-hidden. In use there are three cases: decoration, action and meaning.

CaseMarkupExample
Text beside it (decoration)<svg aria-hidden="true">Text .btn, callout, .check
Only content of a buttonThe name goes on the button: <button aria-label="…">.icon-btn
Carries meaning on its own<svg role="img" aria-label="…">Status icon in a table cell
Do · the icon has a name

eu-west-1

Don't · the meaning is only in the drawing

eu-west-1

A screen reader reads the right-hand line as just "eu-west-1"; nobody hears that the region has a problem. On an .icon-btn, the aria-label starts with a verb and says what will happen: "Close viewer", not "Close".
