Definition listName–value pairs, captions and reading text.

Three text parts: dl.kv for short name–value pairs, .figcap under a figure or table, .prose for long reading. Inline code, mono text and links live inside them.

Classes
.kv · .figcap · .prose · .mono
Sizes
.kv name column 200px; single column when the content column is narrower than 640px · .prose 72ch · .figcap 80ch
JS
Not required

01

Definition list

dl.kv is a two-column grid: bold name on the left, value on the right. The value should be short: a word, a number, an identifier.

Example · service card
Service
web-api
Owner
platform team
Region
eu-west-1
Replicas
3 (min 2, max 8)
Status
healthy
HEALTHCHECK
GET /healthz · 10 s interval

The name column is fixed at 200px; the value column takes the remaining space and stops at 80 characters. When the content column (main) is narrower than 640px, name and value stack; this is a container query, so it looks at the column, not the window. A dl should hold only dt and dd pairs; give each name one value.

03

States

A definition list has no status color of its own; the status is told by a badge inside the value. One rule each covers long, empty and not-yet-known values.

Example · deployment record
Status
retrying attempt 2 of 3
Security scan
awaiting signature

123456789012.dkr.ecr.eu-west-1.amazonaws.com/web-api@sha256:4c1e9a0b7d2f
Finished
—not yet (job running)
Rollback
—not defined
ValueRule
Status.pill.s-* or .state.s-* and one word; don't color the dd
Long identifierWrite it inside <code>: it breaks anywhere, so the column doesn't overflow
Empty or unknownA visible “—” plus a .visually-hidden word for screen readers; never leave the dd empty

05

Reading text

prose keeps lines at 72 characters and sets the body in secondary ink. It can hold headings, lists, inline code, mono text and links.

Example · release note

Release note 1.9.0

This release adds a quiet hours window to alarm rules. Alarms that fire inside the window are recorded but not sent to the on-call engineer; see the definition list section for details.

What changed

  • Any rule can take a quiet_hours field.
  • The default time zone is Europe/Istanbul.
  • The old mute_until field goes away in the next major release.

Upgrading

  1. Check the rule files with alarm lint.
  2. Deploy to staging first, then to prod a day later.

code draws a background and is for values the reader will type or copy. .mono draws no background; it is for technical names that aren't copied, such as a time zone or a record type.

06

Do / don't

A definition list is a dictionary, not a story. As values grow longer, the reader stops scanning the column.

Do · short value, details in the text
Retention
14 days
Encryption
KMS, customer key
Don't · a paragraph in the value
Retention
Backups are kept for fourteen days for audit purposes and then deleted automatically; if you need them longer, write to the platform team.
Do · steps when there is an order

  1. Take the backup

  2. Run the migration

Don't · write an order into a definition list
First
Take the backup
Second
Run the migration
Accessibility

A screen reader announces a dl as a definition list and says how many items it has. Children other than dt/dd break that structure. Links stay underlined inside text; don't set them apart by color alone.
