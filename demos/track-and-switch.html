Track and switchWhich way traffic goes, and which way is closed.

Routing drawings use the language of railways: the track is a heavy line, the switch is where the path splits, the unused branch is a ghost, and the filter arm is red. Traffic decisions like canary, blue/green and regional failover read at a glance in this language.

01

Anatomy

The track is the path that carries traffic and is drawn heavy. At the switch the path splits; the branch not in use stays a ghost. The filter arm cuts across a track and is red.

The switch point is marked with circle.fill-draw. The filter arm is a post (.ln-draw), a pivot (circle.ln-draw.fill-paper) and a heavy red bar across the track; the path beyond the arm is a ghost, because nothing reaches it. Destination labels are .tag line labels and sit at the end of the track; an idle one gets a dashed frame with .tag.is-ghost.

02

Switch types

The same switch draws three different decisions: splitting traffic by weight, cutting over from one side to the other at once, or closing off the unhealthy side.

In a canary both paths are real, so both are drawn solid. The one carrying most of the traffic is heavy and the one carrying a little is thin; the ratio is written above the line.

In blue/green the switch flips in one move. In the “after” drawing the blue branch is a ghost: it is the previous position and stays as the rollback path. There is no in-between state, so the drawing is two separate panels, divided by a dashed guide line.

Accessibility

The difference between a heavy line and a ghost line is visual. Which path is open and which is closed must also be stated in the destination label (.state) and in the caption. A blocked path is drawn not only in red but also with a dashed pattern and a stop mark.
