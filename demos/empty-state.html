Hendese · Components

Empty stateNo data yet; why, and the next step.

.empty stands in place of a list, a table or a figure and says why there is nothing there. It has a dashed frame: in this language a dashed line means “not real yet”. The heading is a .chip, the body is one sentence, plus one optional button.

Classes
.empty · inside it .chip, <p>, .btn
State
Loading: aria-busy="true" on the region plus text · Error: .co-trouble
JS
Not needed

01

Anatomy

Three parts, stacked and left-aligned: a chip that names what is missing, a sentence that says why and what comes next, and one optional action.

Example · complete

No alarms

No alarms have been defined for report-cron yet. Failed runs are not reported to anyone right now.

.empty
The container. Dashed frame, padding and a left-aligned grid; it resets the margins of the paragraphs inside.
.chip
The name of what is missing: “No deployments”, “No results”. A noun phrase, not a sentence.
<p>
Why it is empty and what the reader can do. One or two sentences.
.btn
Optional. The one action that fills the gap; not drawn if the reader lacks permission.
Example · no button, information only

No changes

Nothing has been merged into main since the last deployment.

02

In place of a table

A table with no rows is not drawn: an empty header row tells the reader nothing. The toolbar (title, filter) stays; .empty takes the table's place.

Example · the filter returned nothing

Deployments · prod · last 7 days

No results

There were no failed deployments to prod in the last 7 days. Clear the filter to see all deployments.

An empty result from a filter and having no data at all need different sentences. In the first, the reader changes the filter; in the second, they create the first record. After a filter, the button clears the filter; it does not create a new record.

03

Inside a sheet and a dark scene

If a figure has no data yet, the sheet is still drawn; .empty sits where the drawing would be. The figure name and caption stay, so the reader knows what is coming.

Example · sheet, no measurements yet
Example · dark panel

Open incidents · eu-central-1

No open incidents

The last incident was closed 12 days ago. Nothing to hand over at the on-call handoff.

04

States: empty, loading, error

All three sit in the same place but say different things. Empty: the request succeeded and there is no result. Loading: no answer yet. Error: the answer never came or is broken. Showing an error as an empty state misleads the reader.

Example · three states side by side

Empty

No jobs

There are no scheduled jobs on this cluster.

Loading

Loading jobs…

Error

Could not load jobs

The cluster API returned 503. Try again in a few minutes.

StateMarkupWhat it says
Empty.emptyWhy there is nothing and what the reader can do.
Loadingaria-busy="true" on the region plus plain textWhat is being waited for: “Loading jobs…”. If it takes long, what it is still waiting for (“2 of 3 regions in”).
Error.co.co-troubleWhat could not be loaded, why (if known) and what can be done.
No skeletons, no spinners

The package deliberately ships no skeleton rows or spinners. A skeleton draws data that has not arrived as if it were real; in this language a solid line means real. A spinner needs motion and does not say what is being waited for. The finished state is text: it says the same thing with motion off, in print and in a screen reader.

Example · refresh: loading, then empty

No releases

No releases of web-api were published this week.

While it waits, the region carries aria-busy="true"; the screen reader skips the intermediate changes and reads the region once when the answer arrives. The attribute is removed when the answer arrives.

05

Do / don't

An empty state says why it is empty and what the reader can do next. “No data” on its own says nothing, and an error is not emptiness.

Do · reason and next step

No secrets

No secrets are defined in the staging environment; services run with the default configuration.

Don't · no context, an error shown as emptiness

No data

Nothing to show.

  • The chip names what is missing (“No secrets”); “No data” is the same everywhere and says nothing.
  • One action. The action that fills the gap; no button that does nothing, like “OK”.
  • If the request failed, it is an error, not an empty state. A reader who sees “No records” and believes there really are none makes the wrong decision.
  • Text instead of skeletons and spinners. The loading state says what is being waited for.
