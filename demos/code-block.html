01

Anatomy

The header row has the file name on the left and the language and copy button on the right. The pre must be keyboard-focusable; long lines scroll sideways.

02

Languages and highlighting

The package includes no syntax highlighter. Four classes are enough: k for a key or command, s for a string value, c for a comment, v for a variable or number.

03

Copying and long lines

The copy button takes the plain text of the code element; it drops trailing blank lines and leaves out the highlighting tags. The result shows on the button for 1.6 seconds.

Example · try it, then paste

On a successful copy the button gets data-state="done" and turns green; without clipboard permission it retries with a hidden textarea, and if that fails too it gets data-state="fail", turns red and reads Copy failed. Because the label is aria-live="polite", the result is announced to screen readers too. Override the button text like this:

Long lines do not wrap; the block scrolls sideways and the page does not overflow. Thanks to tabindex="0" on the pre, keyboard users can focus the block and scroll it with the arrow keys.

04

Annotations and cursor

Two extra layers: pre.annotated puts colored labels on groups of lines; .ln.cur highlights the line running now. Neither changes the copied text.

Example · an annotated migration script

There are five group colors (.g1–.g5); the order carries no meaning, as long as adjacent groups get different colors. Color only separates groups; data-label says what each one is. In a narrow column the labels hide and the colored rule stays.

For the execution cursor, wrap each line in .ln and put the line break inside the </span>. The button below moves the cursor to the next line.

05

States

A code block's state lives in the copy button and in focus. The button has three states; text signals two of them, and text plus color the third.

Example · copy and watch the button
StateButton textLookSet by
ReadyCopyThin border, light inkMarkup
CopiedCopiedGreen border and text, 1.6 secondsHendese.init()
Copy failedCopy failedNo color change; text onlyHendese.init()
Focus—A 2px inset ring on the pre, a light blue ring on the buttonBrowser (:focus-visible)

The script sets the result class and removes it again; do not set it by hand in the markup. A block without a header has no button, so it has no state either. The copy button has no disabled state: text that should not be copied does not go in a code block. A line's “running now” state is given with .ln.cur (see the section above).

06

Do / don't

A code block exists to be copied. What the reader pastes must run; prompts, output and decoration stay out of the code.

Do · the command only
Don't · prompt and output together
Do · little highlighting, in meaningful places
Don't · everything highlighted in one color
Accessibility

The colors pass the contrast threshold on --code-bg in both themes. The copy button has visible text; do not leave the icon on its own. Code is given as text, not as a screenshot: it stays searchable, zoomable and copyable.
