Intro

Hendese · Components

CalloutA side note that does not break the flow.

A callout adds a short note with a left rule next to body text. There are seven types; color and icon follow the type, and the label text is free. The body can hold paragraphs, lists and code.

Classes
.co · .co-info · .co-important · .co-tip · .co-warn · .co-sec · .co-success · .co-trouble
Status
The type is a role; override the color with .s-* if needed
Parts
.co-ic (icon) · .co-label (label) · .co-body (body)
JS
Not needed

01

Seven types

Each type has a fixed color and icon. All the notes below come from the same job: moving a domain to a new DNS provider.

Example · DNS migration notes
Info

The old records have a TTL of 3600 seconds; a change reaches everywhere within an hour at most.

Important

Lower the TTL to 300 24 hours before the move; otherwise rolling back also takes an hour.

Tip

Check the records in advance by querying the new server directly: dig @ns1.new-provider.net api.example.com.

Caution

The moment you change the NS records, the MX records in the old zone become unreadable; move the mail records first.

Security

The provider API key is issued only for the duration of this job; it is deleted from the vault when the job ends.

Done

All five public resolvers return the new address.

Troubleshooting

If you get SERVFAIL, the DNSSEC signature may still use the old key; update the DS record at the registrar.

02

Anatomy and label

Three parts: icon, label and body. Icon and label share a line; the body sits below at full width. The label does not have to be the type's name; it can state the note's subject.

Example · a single callout
Maintenance window

During the migration the orders table stays closed to writes for about 40 seconds.

Example · same type, different labels
No undo

A deleted snapshot cannot be recovered.

Changed in version 3.0

The retry setting now takes milliseconds, not seconds.

Platform team only

This step needs the admin role on the production account.

Counts as done

The error rate on the dashboard stays below 0.1% for 15 minutes.

The label is set in uppercase. On a page in Turkish (lang="tr") it follows Turkish casing rules (i → İ). To use an English word in a Turkish label, wrap it in lang="en" or use the Hendese.init({ englishStems }) option.

03

Long body

The body can hold several paragraphs, lists and a code block. The callout stays 80 characters wide, so a long note is still readable.

Example · body with a list and code
Worker queue is not draining

Symptom: billing-worker looks healthy, but the number of messages in the queue keeps growing.

Check in order:

  • Is the worker's visibility timeout shorter than the job's duration?
  • Are messages landing in the dead-letter queue?
  • Is a schema change from the last release rejecting messages?

If the count is above zero, roll back the last release and retry the schema change in a separate release.

Note

The body only adjusts paragraph margins. If a callout ends with a list or a code block, the space below stays slightly larger, so closing long notes with a paragraph is a good habit.

04

States

A callout type is a role, not a status: co-warn means “a step that needs care”, not “something is wrong right now”. You can override the color with .s-*, but you rarely need to.

Example · fixed role, changing status
Last deployment · succeeded

web-api:1.9.0 went to prod at 10:42; 3 of 3 replicas ready.

Last deployment · failed

web-api:1.9.1 failed its health check; the previous version keeps running.

The note always has the same type (a summary of the last deployment); only its outcome changes. The color comes from .s-ok or .s-bad based on that outcome, and the label states the outcome too. If the outcome changes live, use .readout with aria-live instead of a callout.

Do · the role carries the meaning
Counts as done

All five resolvers return the new address.

Don't · role and color contradict
Caution

All five resolvers return the new address.

When a warning icon and a “Caution” label are drawn in green, readers cannot tell which to believe. The rule: if the role is right, do not add .s-*; add it only when the role stays fixed and the outcome changes. A callout has no disabled or pending state; give a pending region aria-busy="true".

05

In context

A callout does not stand alone; it sits right below a step or a paragraph, close to what it refers to.

Example · inside a step

  1. Flush the cache

    Run FLUSHDB on the cache-eu cluster.

    Caution

    Database load doubles for the first few minutes; do it when traffic is low.

  2. Watch the warm-up

    Wait until the hit rate on the dashboard goes above 80%.

Example · between paragraphs of body text

The cost report is generated on the first business day of each month and compares spend per account with the previous month.

Tip

Untagged resources add up in the report's unallocated row; shrink that row first.

Every row in the report belongs to a team; a row with no owner is shut down the following month.

Example · inside a dark scene
Access window

Temporary admin rights are revoked automatically after 2 hours.

Approved

The request passed two approvers.

06

Do / don't

A callout draws attention; add one to every paragraph and none of them does. One or two per section is enough.

Do · one note, the right type

The new region opened as eu-central-1.

Important

The bucket in the old region will be deleted in 30 days.

Don't · stacked notes
Caution

The new region opened.

Important

It is called eu-central-1.

Info

The bucket will be deleted.

Do · a warning describes a risk
Caution

This command changes the settings of every environment at once.

Don't · warning color on routine information
Caution

This page is updated every week.

07

Accessibility

The type lives in the color and the icon, and neither reaches a screen reader. The label carries it.

  • The label is visible text and is read aloud; pick a word that names the type, like Caution or Security, or state the subject (No undo).
  • The icon is decorative; its <svg> has no title and is not read.
  • A callout is not a role="alert". It is already there when the page opens; use a separate aria-live region for a live error message.
  • The colors pass the contrast threshold in both themes; inside .scene-dark the dark values are used.
