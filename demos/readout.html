Hendese · Components

ReadoutThe result of a calculation, in one line.

.readout writes the result of a choice, an input or a calculation in a short line with a left rule. The bold part is the result itself; .s-ok, .s-warn, .s-bad and .s-sec color the rule and the bold text by status.

Classes
.readout · .s-ok · .s-warn · .s-bad · .s-sec
Old names
.readout.ok · .readout.bad (work until 1.0)
Accessibility
aria-live="polite"
JS
The package does no calculation; the page script writes the text

01

States

Neutral, success, warning, error and security. Color alone carries no meaning: the result itself is also stated in the bold text.

Example · five statuses

3 replicas running; last deployment 14 minutes ago.

Migration done. 1.2 million rows moved in 4 minutes 10 seconds.

Close to the limit. Disk usage 82%; warning threshold 80%, alarm 90%.

Budget exceeded. October spend $4,820; limit $4,500.

Key expires in 3 days. Rotate the deploy-bot access key.

A readout is a paragraph container; it can hold several <p> elements, but an explanation longer than two lines fits better in a callout (.co). In the neutral status the left rule uses the drawing color. .s-warn is new: there used to be no separate status for “close to the limit”. The old .ok and .bad names give the same color until 1.0.

03

In context

A readout looks the same under a card, on a dark panel or in a narrow column; only its text gets shorter.

Example · under a card, cache hit rate

cache-redis · eu-west-1

2.4 million reads in the last hour, 2.21 million hits.

92.1% hit rate · above the 90% target.

Example · dark panel, DNS propagation

api.example.com · A record

6 / 8 resolvers return the new address; on the other two the TTL is 212 seconds.

ns-2 is not responding. Last successful query 09:41.

Example · narrow column

12 workers · 340 jobs queued, estimated drain 6 min.

04

Do / don't

Result first, then the reason. If only the color states the status, the readout is incomplete.

Do · bold result, short reason

Pattern does not match. The tag has seven hex digits, not eight.

Don't · color only

The test result has been evaluated according to the rules stated above.

Accessibility

Give a live-updating readout aria-live="polite"; the screen reader reads the change once typing stops. A static readout does not need it. In a readout rewritten on every keystroke, keep the text short: the reader hears all of it every time.
