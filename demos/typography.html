TypographyTwo families and a pixel face.

IBM Plex Sans for body and headings, IBM Plex Mono for code and labels, Pixelify Sans for Hoca only. All three ship embedded in the package; Turkish letters are in the latin-ext subset, and no external requests are made.

The scale was set up in 0.2. In-between values in components were snapped to the nearest step; the most visible changes are in labels (10.5px → 11px) and the table body (14.5px → 14px). Text inside a drawing is outside the scale: an expression like max(10.5px, calc(12 * var(--u))) makes it grow and shrink with the drawing. Hoca's pixel face also keeps its own size, because it is tied to a 3px grid.

02 About 3 min

Scaling rule

The replica count is recalculated every 30 seconds from the average of the last five minutes.

If more than 500 jobs pile up in the queue, a new replica starts; if the depth drops below 50 and stays there for 10 minutes, one replica stops. Short spikes don't trigger scaling.

Inline elements

Four small tools for running text: inline code, mono text, the label chip and the caption. Code blocks are a separate system that stays dark in both themes.

Note 7 · cache

Product pages are kept on cache-eu-1 for 5 minutes. When a price changes, the key product:{id}:v2 is deleted; the page is rebuilt on the next request. For bulk updates, bump the version prefix instead of deleting keys one by one.

05

Turkish characters

The latin-ext subset of the Plex families covers every Turkish letter. The real trap isn't the letters; it is uppercasing with CSS.

Example · the same sentence in three families

Pijamalı hasta yağız şoföre çabucak güvendi. ÇĞİÖŞÜ çğıöşü

Pijamalı hasta yağız şoföre çabucak güvendi. ÇĞİÖŞÜ çğıöşü

Pijamalı hasta yağız şoföre çabucak güvendi. ÇĞİÖŞÜ çğıöşü

On a lang="tr" page, text-transform:uppercase applies the Turkish rule: i → İ, ı → I. That is right for Turkish words and wrong for English technical words set in uppercase. .chip, .ch-num, table headers and demo labels are set in uppercase. The two chips below are marked as Turkish to show the effect.

06

Limits of the pixel face

Pixelify Sans is Hoca's voice only: the speech bubble and the plate on the rail. It is never used for body text, headings or data.

Do · short speech, one sentence

The cache is warm, we can go on.

Don't · data and long text

0O 1l 5S 8B · request ID 10l0O-8B5S: you can't tell these apart. Long paragraphs in a pixel face tire the eye fast, too.

Why so narrow

In a pixel face, similar characters (0/O, 1/l) don't separate, digits aren't equal width, and letter spacing turns uneven at small sizes. Only weights 400 and 500 ship. Hoca's bubble can switch to mono with .hoca-bubble.mono; use it for speech that contains code or values.

Weight limit

The package weights are fixed: mono 400/500/600, sans 400–700, pixel 400/500. Write a weight that isn't listed and the browser fakes a bold.
