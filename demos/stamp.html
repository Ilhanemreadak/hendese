StampSeal a name.

.stamp is a double-framed name plate: a small type label on top, the name in large mono below. It names the single subject of a figure, a section or a decision: who approved it, who owns it, which version.

Classes
.stamp · .stamp-k · .stamp-name
Width
Fills its container; narrow it with max-width
State
No status color of its own; put a .state.s-* next to it
JS
Not needed

01

Anatomy

The outer frame is in the drawing color, the thin inner line in pencil. The label says what kind of name it is; the name says itself.

Example · an ownership plate
Owner billing-worker
.stamp
The container; laid out as a grid, text centered. It is a block element and fills its whole container.
.stamp-k
The type label: uppercase, letter-spaced mono, in the drawing color. For example “Owner”, “Version”, “Approved by”.
.stamp-name
The name itself: 22px bold mono. If it does not fit, it breaks anywhere.

02

Uses

The same markup answers three different questions: who approved this, whose is it, which version.

Example · approval, ownership, version
Approved by security team
Owner platform
Version v2.14.0
Example · a long name
Internal endpoint web-api.prod.eu-west-1.internal

A long name breaks onto two lines, but the stamp loses readability. If the full name is not needed, put the distinctive part in the stamp and the full name in the text next to it.

03

In context

A stamp shows the subject at the start of a section, the signature under a decision, or the owner in the corner of a card.

Example · a release notes header
Version v2.14.0

Invoice export and faster search

  • Invoices can be exported as CSV.
  • Due-date searches are 6 times faster with the due_date index.
  • The old /v0/invoices endpoint was removed.
Example · an access request decision

Access request · #2318

Read-only access to the prod database, for 7 days, for an incident review.

Approved by data team
Approved expires October 13, 2026

04

States

A stamp seals a name, not a status. Its color and frame are always the same; the decision goes in the .state label next to it, and an empty name is written as a dash.

Example · the same stamp, three decisions
Approved bysecurity team
approved
Approved bydata team
rejected
Approved by—not assigned yet
pending

Do not remove the stamp for a name not yet assigned; write “—” and leave a .visually-hidden word for screen readers. By the language's rules, “not real yet” is drawn dashed, but the stamp has no dashed form: the label says it is pending. Do not change the color or frame with inline styles.

05

Do / don't

A stamp is for a name, not a sentence. It is not something to click either; actions belong to a button.

Do · short, a single subject
On-call payments team
Don't · a sentence and an action
Note Click here to approve
Accessibility

A stamp is plain text; a screen reader reads “Owner billing-worker”. Keep the label and the name in the same container so their meaning stays linked. Write the status (approved, rejected) in the .state label next to it, not in the stamp's color: the stamp has no status colors.
