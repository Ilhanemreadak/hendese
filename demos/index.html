Basics

  • ColorsSurface, ink, accent, status, service and code tokens; light-dark(), theming with a single color, overrides, high contrast and forced colors.
  • TypographyThree families, the --fs-* type scale, heading hierarchy, inline elements, the Turkish uppercase trap and the limits of the pixel face.
  • Scale and motionThe --sp-* spacing ruler, --r-*, shell sizes, --z-*, a single motion set (--dur-1..5, three curves) and deprecated aliases; reduced-motion behavior.
  • IconsThe sprite, sizes, use inside components, adding a new icon and aria rules.
  • Page shellTop bar, rail, hero, chapter head, rulers, reading bar, skip link, [data-section], the col container and the full skeleton.

  • Checkbox, radio and range.field-check checkboxes and radios, a range slider + <output>; how they differ from chips.
  • Tabs.tabs[data-tabs], role="tab|tabpanel", keyboard, the hendese:tab event; config formats and environment settings.
  • Dialogdialog.dialog, .dialog-head, .dialog-foot; return value, type-the-name delete confirmation, dialogs with a title block and a register.
  • Dimension notepopovertarget + .dim-tip[popover]; in running text, in a field heading, in a table header; position and dismissal.
  • Empty state.empty; in place of a table, inside a sheet and a dark scene; telling empty, loading and error states apart.
