Hendese · Components

TableRows and columns for comparing.

The .tbl container frames a <table> and scrolls it sideways when needed. The first column is in ink, headers are mono and uppercase. On narrow screens rows turn into cards; Hendese.init() writes each cell's label.

Classes
.tbl · .tbl.wide · th.num / td.num (number column) · in cells code, small, .pill, .state, .plus, .minus
Minimum width
620px (.tbl) · 820px (.tbl.wide)
JS
Hendese.init() writes data-th on every td (the narrow-screen label)

01

Anatomy

The .tbl container holds a plain table. thead is required; the narrow-screen labels are read from it. In a cell, small is for secondary info and code for a value that must not wrap.

Example · environments
EnvironmentClusterRegionLast deployment
prodeks-prod-01eu-west-1Today 10:42 (1.8.2)
stagingeks-stg-01eu-west-1Today 09:15 (1.9.0-rc.2)
deveks-dev-01eu-central-1Yesterday 18:03 (main@4c1e9a0)

The container's border, corners and background come from .tbl; do not put a class on the table. The last row's bottom rule is removed automatically.

02

Width and scrolling

A table is at least 620px wide, 820px with .tbl.wide. If the container is narrower, the table does not squeeze; it scrolls sideways.

Example · a wide table, CI stages

A scrolling container

If the container scrolls, keyboard users must be able to reach it. Give .tbl tabindex="0", role="region" and an aria-label that describes the table; the same rule as for the pre in code blocks.

03

Cell content

A cell holds a single fact: a value, a status, a number. Give a number column .num: it aligns right, uses equal-width digits and does not wrap, so comparisons read top to bottom.

04

States

A table row has no status color of its own; the badge in a cell carries the status. A number column, empty cells and a status column together.

Example · a deployment summary
ServiceReplicasp95 (ms)ErrorsLatest versionStatus
web-api3 / 31820.02%1.9.0healthy
billing-worker2 / 31,2400.90%4.2.1slow
report-api0 / 2—no data—no data0.7.3down
legacy-cron0 / 0—no data—no data—no versionoff

Table 4. An empty cell shows “—”, and screen readers hear “no data”. Zero is a value and is written (0 / 2); a dash means “no information”.

WhatMarkupWhy
Number column<th class="num"> and <td class="num">The header aligns right too; digits line up
Empty cell<span aria-hidden="true">—</span><span class="visually-hidden">no data</span>An empty td is not read; the reader thinks the value was forgotten
Row status.pill.s-* or .state.s-* in the last columnColoring the row breaks the scanning pattern; a badge carries both color and a word

If you need equal-width digits outside a number cell (a counter, a duration), use the .tnum utility class; do not write an inline font-variant-numeric.

05

Narrow screens

Below 720px the header row hides and each row becomes a card. Each cell shows its column name on the left; init writes these names onto every td as data-th.

Example · labels written by JS
WorkerQueueConcurrencyStatus
billing-workerinvoices8running
mail-workeremail4paused

Reading the labels…

The card view is a container query: it kicks in when the content column holding the table (main) is narrower than 720px. A narrow box inside the page does not trigger it on its own; narrow the window to see it. If JS does not run, the cell labels are not written; the cards still form, but without column names.

Short headers

The card label fits in 88px. Keep headers short (if Concurrency does not fit, write Parallel); put the unit in the cell, not the header.

06

Do / don't

A table is for comparing. The reader must be able to scan a column top to bottom; a paragraph in a cell, or a layout table, breaks that.

Do · one fact per cell
AlertThresholdWindow
5xx rate2%5 min
p95 latency800 ms10 min
Don't · sentences in cells
AlertDescription
5xx rateIf more than two percent of requests return an error within five minutes, the on-call is notified.
p95 latencyIf it exceeds 800 milliseconds for ten minutes.
Accessibility

Headers must be real <th> elements; a screen reader says the column name as it reads a cell. Do not use tables for page layout. If you need a title, put a .chip before the table or a .figcap below it.
