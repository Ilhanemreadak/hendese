The scale was set up in 0.2. In-between values in components were snapped to the nearest step; the most visible changes are in labels (10.5px → 11px) and the table body (14.5px → 14px). Text inside a drawing is outside the scale: an expression like max(10.5px, calc(12 * var(--u))) makes it grow and shrink with the drawing. Release 1.14Queue workers now scale themselves.

billing-worker grows between 2 and 12 replicas based on queue depth. This note covers what changed and what you should check.

02 About 3 min

Scaling rule

The replica count is recalculated every 30 seconds from the average of the last five minutes.

If more than 500 jobs pile up in the queue, a new replica starts; if the depth drops below 50 and stays there for 10 minutes, one replica stops. Short spikes don't trigger scaling.

Why so narrow

In a pixel face, similar characters (0/O, 1/l) don't separate, digits aren't equal width, and letter spacing turns uneven at small sizes. Only weights 400 and 500 ship. Hoca's bubble can switch to mono with .hoca-bubble.mono; use it for speech that contains code or values.

Weight limit

The package weights are fixed: mono 400/500/600, sans 400–700, pixel 400/500. Write a weight that isn't listed and the browser fakes a bold.
