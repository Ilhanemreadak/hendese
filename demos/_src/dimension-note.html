  • The key information is in the text. If something that changes the decision, like “cannot be undone”, appears only in a note, most readers never see it.
  • No tooltip on hover. title and hover tips are often invisible on touch screens, with a keyboard and under a screen magnifier. The package's note opens only on click.
  • The button label is a question (“Why 512 MiB?”), not “Info”; a screen reader user knows what it explains without opening the note.
  • The note comes right after its button. Use <span popover> inside a paragraph; collecting all notes at the end of the page breaks the reading order.
  • The note is short. One or two sentences or one calculation. If it is longer, move it into the text or a callout.
