Requesting Hoca

The left figure is requesting. Hoca is next to the queue, with his clipboard.

260 px

The threshold is in viewport pixels, not drawing units. At 1440px wide the two distances are about 170 px (walk) and 480 px (fade); in a narrower window the distances shrink.

When section tracking finds the active section, it checks for data-hoca="quiet": if present, Hoca at home drops to 45% opacity and the rail's Hoca box fades. It suits places where Hoca has nothing to say, such as long reference tables, API sections and rules. If a scene in this section requests him, he still speaks; quiet only affects how he stands at home.

Hendese.hoca.dismiss() sets the shared dismissed flag and wakes the loop. Scenes read the flag and return hoca: null; the two figures above are written this way. Hoca stays at home. To undo it, set Hendese.hoca.dismissed = false.

On. Scenes can request Hoca.

Not persistent

The flag lives only while this page is open; when the page reloads, Hoca comes back. To make it persistent, store the preference yourself and set Hendese.hoca.dismissed = true before Hendese.start().

When live mode turns off, the engine hides the fixed layer and puts a copy inside the drawing for every scene that has a still (left/top are converted from drawing units to percentages). If still is a function, it is read again on every Hendese.refresh() call; if it returns null, that scene gets no copy. That is why the choice and dismissal buttons above call refresh() on every change (in live mode the call does not interrupt a handover): under reduced motion, too, Hoca moves to the chosen figure and disappears when dismissed.

Below 1100px and in print the copies are hidden too. Since Hoca carries no information in any mode, nothing is lost.

MemberWhat it does
#hoca-homeThe home on the rail. If it is missing and no scene has a still, Hoca is never created.
data-hoca="quiet"On a [data-section] element: while that section is active, Hoca at home is 45% opaque.
render → {hoca}{x, y, pose, face, bubble, bubbleUp, tag, squash, hidden}, in drawing units; null → no request. hidden: true keeps ownership but hides Hoca; when he shows again, he appears in place without walking.
stillAn object or a function; the still copy under reduced motion. null → no copy.
Hendese.refresh()Removes the still copies and places them again from the still values. In live mode it does not touch the handover state; a walk or fade in progress is not interrupted, so it can be called unconditionally on every state change.
Hendese.hoca.dismiss()dismissed = true and wakes the loop.
Hendese.hoca.dismissedA readable / writable shared flag; writing it also wakes the loop.
Hendese.lockTo(id)The part-navigation lock; while it holds, scene requests are ignored: Hoca fades to home, and when the lock ends he appears in the target scene.
