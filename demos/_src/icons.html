In large text, the icon grows too.

Every <svg> in the source that has no viewBox and directly contains a <use> takes its size from the text: 1em × 1em. To change the size, touch the container's font-size, not the icon. The rule sits inside :where(), so its specificity is zero; component sizes (such as .btn svg at 14px) and your own classes always win.

base.css makes every svg a block. For an icon inside a sentence, add .ic: it becomes inline-block, sits on the baseline and doesn't shrink inside flex. The style="width:16px;height:16px" workaround from 0.1 is no longer needed.

  1. Add the symbol

    The id starts with i-; viewBox 24×24, no fill, stroke currentColor. Don't hard-code a color: the icon would ignore the theme and the component.

  2. Build

    npm run build copies the sprite to dist/icons.svg. Part pages (node tools/demos.mjs) read the sprite straight from src/icons.svg.

  3. Carry it to the pages

    The sprite is inline on every page. A new page starts as a copy of docs/_sablon.html (the sprite is inside); when src/icons.svg changes, the sprite on existing pages is updated by hand.

Contract

Icon ids are part of the documented contract. Adding an icon is a minor release; renaming or removing one needs a major release.
