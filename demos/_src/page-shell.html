Why 1100px

The threshold is written in two places, as a media query in CSS and as matchMedia('(min-width:1100px)') in JS, and it is a contract, not a setting. Media queries cannot read variables, so there is no token.

main carries container: col / inline-size. When a component is placed in a narrow column (a side panel, half of a two-column layout, the text column of a sticky scene), it switches to its narrow layout even if the window is wide. To make your own narrow column a container, give it the same name; the nearest col container wins.

To make a section quiet, <article data-hoca="quiet"> is enough. While the section is active, the rail gets .hoca-quiet and Hoca's home turns semi-transparent; scenes do not call for Hoca.
