On a successful copy the button gets data-state="done" and turns green; without clipboard permission it retries with a hidden textarea, and if that fails too it gets data-state="fail", turns red and reads Copy failed. Long lines do not wrap; the block scrolls sideways and the page does not overflow. Thanks to tabindex="0" on the pre, keyboard users can focus the block and scroll it with the arrow keys.

There are five group colors (.g1–.g5); the order carries no meaning, as long as adjacent groups get different colors. Color only separates groups; data-label says what each one is. In a narrow column the labels hide and the colored rule stays.

The script sets the result class and removes it again; do not set it by hand in the markup. A block without a header has no button, so it has no state either. The copy button has no disabled state: text that should not be copied does not go in a code block. A line's “running now” state is given with .ln.cur (see the section above).
Accessibility

The colors pass the contrast threshold on --code-bg in both themes. The copy button has visible text; do not leave the icon on its own. Code is given as text, not as a screenshot: it stays searchable, zoomable and copyable.
