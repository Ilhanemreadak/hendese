Hendese · Basics

Scale and motionSpacing, corners, layers, duration and easing.

Components don't write sizes or durations; they read spacing, corners, shell widths, layer order, transition durations and easing curves from tokens. When the reduced motion preference is on, every transition drops to zero and the finished state shows at once.

Tokens
--sp-1..11 · --r-xs --r-sm --r-md --r-lg --r-pill · --rail-w --side-w --canvas-max --topbar-h · --z-* · --dur-1..5 · --ease-out --ease-in-out --ease-snap
Class
html.motion (live mode)
JS
Not required; the play buttons in the examples are a few lines of page script

01

Spacing scale

Eleven steps, from 4px to 48px. padding, margin, gap and inset read from these steps; values in between are off the scale.

Ruler · --sp-1 … --sp-11
--sp-14 --sp-26 --sp-38 --sp-410 --sp-512 --sp-614 --sp-716 --sp-820 --sp-928 --sp-1032 --sp-1148
Example · the same card, spacing from the scale

Queue · billing-worker

4 replicas, 120 jobs per minute. Depth is under the threshold.

healthy eu-west-1

Inner spacing (padding) and the space between elements (gap) aren't picked from the same step: --sp-7 / --sp-8 inside a card, --sp-2 / --sp-5 between lines, --sp-3 between badges. Values of 0–3px are optical corrections (for example a badge's vertical 1px) and stay off the scale. Spacing inside a drawing is in drawing units, via calc(N * var(--u)).

02

Corners

Five radii: the smallest mark, a control, a card, a large panel and the fully rounded badge. The corner grows with the surface; giving a small chip a big corner makes it look like a button.

The fixed corners from 0.1 (.btn 7px, .icon-btn 8px) were snapped to --r-sm in 0.2; no component in the package writes a raw corner anymore. The drawing language has no corners: everything drawn on a sheet has zero radius, and rounded corners exist only on interface surfaces.

For a document where you want a narrower canvas, one line is enough: :root{--canvas-max:880px}. The ruler lines read the same token, so they move with the new edges.

Layer order

Fixed-position shell elements stack on top of each other; their order is a token. When you add your own fixed element (for example a notice bar), place it between two neighboring tokens. Local stacking of 0–2 inside a component is free.

Old names

In 0.2 no component in the package reads the old names; all three stay as aliases only so your code doesn't break. --t-fast dropped from 160ms to 120ms because it is now tied to the new set. A unit test rejects these names and raw durations (300ms, .25s) in component CSS.

06

Reduced motion

When reduced motion is on in the operating system, base.css pulls every transition and animation duration close to zero. The examples above then jump straight to their final position.

Reading the setting…

This safety net also catches transitions written in an inline style. Still, for any motion that changes position, depends on scrolling or draws attention, the contract is: put the transition under html.motion. That class exists only while JS is running, the screen is 1100px or wider and reduced motion is off.

Do · one property, a token duration
Don't · everything, a fixed long duration

Hover over both. The right-hand button stays in an in-between color for 900ms; the user has long since moved the pointer away. all also animates properties that affect layout.
