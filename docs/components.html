ComponentsBuilding blocks for the reading flow.

From the button to the title block, every component reads only tokens and asks for plain HTML. Each example shows the live result next to markup you can copy.

01

Buttons and badges

Four buttons and three small labels. Buttons are real <button> elements; badges only carry information and are not clickable.

.btn is for actions with text, .icon-btn for icon-only actions; an icon button requires aria-label. .toggle-btn carries its on/off state in aria-pressed: red when pressed (a blocking switch), or the accent color with .is-accent. A disabled button is drawn with a dashed border: disabled removes it from focus, aria-disabled="true" keeps it focusable (the script ignores clicks).

Example · buttons
Example · toggle button (click it)

.pill takes its color from --c and its fill from --c-soft; the .s-* classes set both: .s-ok, .s-warn, .s-bad, .s-sec, .s-neutral, .s-accent and the service colors (.s-gitlab, .s-aws, .s-k8s, .s-argo; the fill is 10% automatically). A badge without a class is neutral and does not inherit its container's color. The old names (.pill-ok, .pill-neutral, .state.ok…) keep working until 1.0.

.state is the status label used in drawings (SUCCEEDED, PENDING…); it sizes itself from the drawing unit --u, which is 1px outside a drawing. It takes its color from the same .s-* classes. .chip is a small uppercase mono label: figure title, column name, counter.

02

Callouts

For side notes that should not break the flow of the text. There are seven kinds; each has a fixed color and icon, and a free label.

Example · seven kinds
Info

A tag combines the service name and the environment: web-api:prod-3f9c2a1b.

Important

If the tag pattern changes, the sync tool no longer sees the new image.

Tip

Run docker build . locally first; errors show up faster there.

Caution

Scaling replicas to zero stops the service; do it only in a maintenance window.

Security

Passwords never go into the repository; secrets are read from the vault at runtime.

Done

The new pods are ready; the old replicas are shut down.

Troubleshooting

If the image cannot be pulled, check the region (eu-west-1) first, then the tag.

03

Code blocks

Code blocks stay dark in both themes. The header row carries the file name, the language and the copy button; copying takes only the <code> text.

Highlighting is done by hand: .k key, .s string value, .c comment, .v variable. The Copy button works automatically through Hendese.init().

Example · code block

Annotated block

pre.annotated opens a label column on the left; each .grp line group gets a line in its own color (.g1–.g5) and a data-label label. On narrow screens the labels hide and the colored line stays.

Example · annotated block

Diff gutter

Changed lines are marked outside the code, with <i style="--l:N" data-m="Δ1"> markers inside .diff-gut; the copied text stays clean. Refer to the same marker in the text with .diff-key.

Example · diff gutter

The service now runs in its own namespace; replicas went up to three.

Execution cursor

Wrap each line in .ln; the line running right now gets .ln.cur. The text color does not change; only the line background and the left rule are highlighted. In scenes, JS moves the cursor.

Example · execution cursor

Example · .prose and .figcap

Every build produces a new tag. The sync tool watches only tags that match the pattern; images outside the pattern stay in the registry but never reach the cluster.

Figure 4. The tag pattern is the only contract between build and sync.

.prose keeps line length at 72 characters and sets paragraphs in --ink-2. .mono is for inline mono text; unlike code, it draws no background. dl.kv collapses to one column when the content column is narrower than 640px.

06

Steps

Numbered cards for sequential work. The number comes from the list counter (start works); each step has a heading, a short description and an optional check line.

Example · ol.steps

  1. Create the image repository (done)

    Name the repository after the service: web-api.

    Check: the repository shows up in the list.

  2. Connect the build

    Every push to the source repository produces a new tag.

    Check: the first build finished green.

The current step gets a 2px drawing border through aria-current="step". data-state="done" turns the number green; data-state="blocked" turns it red and the border dashed. Because the state does not reach screen readers, also say it in visible or .visually-hidden text. The check line can take .check.s-warn and .check.s-bad.
