Hoca
Intro

Hendese · Motion engine

Sheets that draw as you scrollAnimation is the path to the finished drawing, not the drawing itself.

One rAF loop, three scene types (pin, sticky, fig), one readout (the HUD) and Hoca walking between scenes. All of it sleeps when idle; with motion off, the page rests in its finished state.

Modules
core · nav · scenes · hud · hoca
Threshold
≥ 1100px, no reduced motion
Dependencies
none

01

Contract: default = finished state

Each scene's HTML and CSS describe what it looks like once the animation is done. In live mode, JS only plays the path to that state.

Live mode turns on when all three conditions hold: Hendese.start() has been called, the screen is at least 1100px wide, and the user has not asked for prefers-reduced-motion. While it is on, html gets .motion and every scene gets .is-live. If any condition changes, scenes shut down, every inline style and class they wrote is cleared, and reset(api) is called.

Rule
Always read CSS variables as var(--k,1): if JS wrote nothing, 1 = finished state. Put live rules inside @media screen{ .is-live … } so print also gets the finished state. Do not read layout inside render(); measuring belongs in measure().

04

Fig scene: a drawing the reader plays

No scroll progress. State and events belong to the page (they work in every mode); the scene only manages Hoca and timed beats. Call api.poke() when state changes.

05

HUD: one fixed readout

A page has a single #hud. On every frame, the most visible of the scenes that return hud pulls the readout into its own .hud-slot.

Markup (once, at the end of the page)

Field names are up to you: each key in the hud object a scene returns is written to the element with the matching data-hud value; fill scales the bar 0..1, and chap comes from chap in the scene registration.

06

CSS-only motion: sketch and reveal

Two tools for small accents that do not need a scene. Both show the finished state in unsupported browsers and under reduced motion.

Pencil sketch → ink

Add .sketch-pending to the container first, then .sketch: the paths in the .pencil group draw in over 2 seconds. The paths need pathLength="1".

Example

[data-reveal]

The element fades in as it enters the viewport (animation-timeline: view()). data-reveal="draw" draws SVG paths (again with pathLength="1"). Do not use it for content that carries the narrative; that is the job of pin and sticky scenes.

07

Narrow variant: a second drawing via container query

If a dense drawing gets cramped in a narrow column, draw a narrow variant of the same sheet instead of shrinking it. The pattern ships in the package: when the fig container (.f-map, .fig-sheet, .sticky-fig) is narrower than 576px, the second drawing takes over. The engine rereads --aw/--ah on every measure.

Pattern · markup only, no page CSS needed

For the scene's Hoca and still coordinates, pick a table inside render with api.aw < 700 ? NARROW : WIDE; api.aw is recomputed on every measure. A live page with examples: Narrow variant. To give the figure column more room when the window is 1100–1279px, add .sticky--dense to the sticky container.
